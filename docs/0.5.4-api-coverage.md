# Hytale 0.5.4 API Coverage

This matrix documents the F2P auth server compatibility surface for Hytale client 0.5.4.

Source evidence:
- HAR captures from `account-data.hytale.com`, `social.hytale.com`, `liveconfig.hytale.com`, and `server-discovery.hytale.com` captured on 2026-06-09.
- Direct curl checks supplied from the official API through the local proxy.
- Santale is accepted as the real F2P source for public server discovery.

Do not add guessed success responses. If a request/response shape is not observed, return an explicit unsupported response or document the gap.

## Status Legend

| Status | Meaning |
| --- | --- |
| Full | Request and response shape are known enough and backed by persistent local data where state changes exist. |
| Empty-state stub | The observed official response is an empty/default state, and we intentionally return that shape. |
| Compatibility | Not official upstream data, but an approved real F2P data source mapped into the observed client response shape. |
| Route only | Route is explicitly handled to avoid wrong catch-all behavior, but exact success behavior is unknown. |
| Unknown | Observed in logs or suspected by client behavior, but no exact response shape is available. |

## Account Data

| Endpoint | Methods | Status | Persistence | Notes |
| --- | --- | --- | --- | --- |
| `/my-account/game-profile` | `GET` | Full | User Redis document | Returns current user profile and persisted skin. Existing response includes local extras not seen in official response. |
| `/profile/uuid/{uuid}` | `GET` | Full | User Redis document, username cache | Returns `uuid`, `username`, and `skin` when known. Unknown users return generated username and `skin: null`. |
| `/player-skins` | `GET` | Full | User Redis document | Returns `activeSkin`, `maxSkins: 10`, and persisted `skins`. F2P intentionally keeps 10, not official 5. |
| `/player-skins` | `POST` | Full | User Redis document | Creates a new saved skin and returns `{ "skinId": "..." }`. |
| `/player-skins/{skinId}` | `PUT` | Full | User Redis document | Updates `name` and/or `skinData`; updates active legacy skin through storage helper. |
| `/player-skins/active` | `PUT` | Full | User Redis document | Sets active skin from `{ "skinId": "..." }`. |
| `/player-skins/{skinId}` | `DELETE` | Full | User Redis document | Removes stored skin. |
| `/my-account/cosmetics` | `GET` | Full | Assets.zip/runtime assets | Returns cosmetics loaded from synced assets when available. |
